# Schriften der Karte

Glyphen von Noto Sans (Regular, Bold, Italic) im Format, das MapLibre für Beschriftungen
braucht, aus `noto-sans.zip` der Veröffentlichung v2.0 von https://github.com/openmaptiles/fonts
(SHA-256 des Archivs: `d117316544b43a5dde7ee761b36e17701e9f85574e181d76a74814240fdbaf34`).
Noto Sans steht unter der SIL Open Font License 1.1.

Enthalten sind nur die Zeichenbereiche für lateinische Schrift (0–1023, 7680–7935, 8192–8447);
für andere Bereiche liefert die API leere Glyphen. Weitere Bereiche lassen sich aus demselben
Archiv ergänzen.
